## Output Files

### Raw FITS Cutouts (`fits_raw/`)
- **Filename Format**: `cutout_<ID>_x<X>_y<Y>_raw.fits`
- **Content**: Raw flux values preserved from original image

### Normalized FITS Cutouts (`fits/`)
- **Filename Format**: `cutout_<ID>_x<X>_y<Y>_norm.fits`
- **Content**: Min-max normalized to 0-1 range

### PNG Visualizations (`png/`)
- **Filename Format**: `cutout_<ID>_x<X>_y<Y>.png`
- **Content**: ZScale-normalized grayscale image

## Normalization Methods

### ZScale (for PNG visualization)
```python
# Robust normalization using percentile-based scaling
# Automatically handles outliers and provides good contrast
vmin, vmax = zscale.get_limits(data)
normalized = (data - vmin) / (vmax - vmin)
```

### Min-Max (for FITS output)
```python
# Simple linear normalization to 0-1 range
# Preserves relative intensity relationships
normalized = (data - data_min) / (data_max - data_min)
```


#------------------------------CNN_prediction.py---------------------------------------

## Overview

This script processes 64×64 FITS cutouts using a trained DenseNet classifier to identify positive detections (transients/supernovae). It uses the same ZScale normalization as the training pipeline to ensure consistent preprocessing.

## Prerequisites

This script requires:
1. **Trained DenseNet model** (`DenseNet169_best.pth` or `DenseNet121_best.pth`)
2. **FITS cutouts** generated by `make_cutouts.py`
3. Directory structure: `cutouts/<tile_name>/fits/`

## Requirements
```bash
pip install torch torchvision matplotlib numpy astropy tqdm scikit-image scikit-learn scipy
```

### Custom Decision Threshold

The decision threshold determines when a detection is classified as positive:
```python
DECISION_THRESHOLD = 0.30  # More lenient (more detections)
DECISION_THRESHOLD = 0.50  # Balanced (default)
DECISION_THRESHOLD = 0.70  # More conservative (fewer detections)
```

**Guidelines:**
- **0.3**: Maximizes recall (catches more transients, more false positives)
- **0.5**: Balanced precision and recall
- **0.7**: Maximizes precision (fewer false positives, may miss some transients)


## Normalization

### ZScale Normalization (Default)

The script uses **ZScale normalization** (same as training):
```python
def normalize_with_zscale(data):
    """
    Astropy's ZScale algorithm for robust normalization.
    - Handles outliers automatically
    - Preserves contrast in low-signal regions
    - Same normalization used during training
    """
    zscale = ZScaleInterval()
    vmin, vmax = zscale.get_limits(data)
    normalized = (data - vmin) / (vmax - vmin)
    return normalized
```
