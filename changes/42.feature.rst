Add real/bogus classification of score-image detections (``sidecar/classifier.py``) using the 24-model CNN ensemble from ``Roman-Supernova-PIT/transient-real-bogus`` on Hugging Face. The models are read from ``photometry.sidecar.real_bogus.model_dir`` (default ``${system.paths.dev_storage}/sidecar/real_bogus_models``) and are downloaded once beforehand with ``python -m sidecar.classifier --download-models``; pipeline jobs never download them. Per-family scores, the ensemble ``real_bogus_score`` and its spread are written to a ``real_bogus_*`` catalog next to the input catalog. The input can be ECSV or Parquet, and the output uses the pipeline's ``--catalog-output-format`` (via ``catalog_io.read_catalog`` / ``write_catalog``). Optionally (``photometry.sidecar.real_bogus.model: 3ch``), a 3-channel ensemble from ``Roman-Supernova-PIT/Real-Bogus-3ch`` scores (science, template, diff) cutouts instead, reading its models from ``photometry.sidecar.real_bogus.model_dir_3ch``; the subtraction then also writes ``rb_science_*.fits`` and ``rb_template_*.fits``.
